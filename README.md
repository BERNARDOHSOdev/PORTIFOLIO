# Bernardo Henrique — Portfólio

Site estático em português, com a foto original fornecida, abertura animada, apresentação e tecnologias interativas. Projetos foram intencionalmente omitidos até a seleção do Bernardo. Nenhum perfil do GitHub está conectado ou vinculado nesta versão.

## Executar

Com Node.js instalado, execute `npm start` nesta pasta e abra http://localhost:4173. Não há dependências para instalar. `npm run check` verifica a sintaxe do JavaScript.

O conteúdo publicável está em `dist`. Os textos estão em `dist/index.html`, o sistema visual em `dist/style.css` e as interações em `dist/app.js`. A foto original está em `dist/assets/bernardo.png`. As fontes usam Google Fonts com fallback local.

Animações podem ser pausadas no rodapé. A preferência de movimento reduzido do sistema é respeitada. Testes de viewport em navegador não substituem testes em um celular físico.
